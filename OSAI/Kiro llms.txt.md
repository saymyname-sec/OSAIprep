# Kiro Docs

> Kiro is a coding agent with an IDE, CLI, and web interface. Kiro helps developers and teams do their best work: turn prompts into executable specs, validate code correctness to find bugs unit tests miss, and build across large codebases with parallel agents that learn from every session. This index lists every docs page with a plain-Markdown companion file suitable for LLM ingestion.

Each URL below has a plain-Markdown companion at the same path with a `.md` suffix (e.g. `/docs/chat` â†’ `/docs/chat.md`). Child pages are indented under their parent. Pages in the "Shared" section are accessible from both the IDE (`/docs/billing`) and CLI (`/docs/cli/billing`) URL trees; the content is identical.
